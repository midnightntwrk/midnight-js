SCOPE — migration guide

  with the dApp's own retained 0.16 instances.

  dApps that must transact pre-fork stay on the last v8-based major
  (adoption-cliff consequence, recorded at D9).

  retirement is a midnight-js policy act (OQ10) — include the graduation-path
  caveat for un-graduated keep-state contracts.

  facing breaking (third-party implementations must add them).
