TITLE: docs: HF migration guide, TROUBLESHOOTING entries, llms.txt/API docs

CONTEXT
Documentation ships WITH the feature, not after. Architecture doc section 10
(lifecycle & removal plan) and the consumer-runtime caveats recorded in
section 3.2 define most of the content. Docs live under docs/ (docs/guides),
never docs/superpowers.

SCOPE — migration guide
- The keepState snippet (dedicated-entry options field, architecture doc
  section 3.3 point 1) + createKeepStateBridge with the dApp's own retained
  0.16 instances (glossary, "Retained stack").
- dApp-side v8 history decoding (./codec import = opt-in; the import
  instantiates the v8 WASM — section 3.4).
- Operator requirement (once OQ12 pins — section 10 gating table): ONE
  dual-capable v9-era proof server, minimum version with dual-ZKIR support;
  DApp-connector local-proving status.
- D9 pre-fork stance (section 8): the new major is READ-CAPABLE ONLY pre-fork
  (raw records + raw contract state work; construct/submit and decoded state
  reads throw) — dApps that must transact pre-fork stay on the last v8-based
  major.
- V2-support statement (section 10 caveat): no upstream sunset — retirement is
  a midnight-js policy act (OQ10); include the graduation-path caveat for
  un-graduated keep-state contracts.
- Implementer note: the two new PublicDataProvider members are implementer-
  facing breaking (third-party implementations must add them — section 3.2
  provider row).

SCOPE — TROUBLESHOOTING
- .tx typed throw on v8 records + the COPY caveat (clone -> tx silently
  undefined; re-guard with isDecodedTxData() — QA-6, section 4.3).
- KeepStateLedgerInstanceMismatchError -> dual-instantiation guide (Vite/WASM,
  section 3.4).
- SEC-9 pre-fork throw on decoded state queries (was null-returning).
- Stale-head error at the fork boundary (re-resolve + rebuild; no auto-retry —
  section 4.4).
- Catching errors by stable `code`, not instanceof (dual npm scopes —
  section 7).

SCOPE — reference
- llms.txt + TypeDoc/API-doc updates for every new public export.
- Compat package README: retirement pre-announcement (deprecate at framework
  v10; LedgerVersion shrink is the compile-time signal — section 10).
