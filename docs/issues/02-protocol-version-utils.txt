SCOPE
- LEDGER_VERSIONS = ['v8','v9'] as const; type LedgerVersion.
- protocolVersionToLedger(int): BOUNDED PER-MAJOR ranges (BC-1/v3.5):
    22_000 <= v < 23_000  -> v8   (major-0 exemption: only node 0.22 attested; 23_000 fail-fasts BY DESIGN — QA-1)

    unknown MAJOR -> typed error (never an unseen minor within a known major;
    no open-ended >= — node 3.x might be a new era).
  This is the SOLE narrowing point from untrusted number to LedgerVersion.

  STRUCTURAL parameters only — types depends on protocol, so protocol must not
  import provider interfaces (layering, NFR4).
